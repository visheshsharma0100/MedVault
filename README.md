# 💊 MedVault

A full-stack Medicine Inventory Management System built with MERN stack.

## 🔗 Live Demo
med-vault-ivory.vercel.app

## 🛠️ Tech Stack
- React + Tailwind CSS
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication

## ✨ Features
- Add, update, delete medicines
- Expiry date tracking with alerts
- Low stock warnings
- Search and filter
- Secure JWT auth
